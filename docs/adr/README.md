# Architecture decisions

Record lasting, consequential tradeoffs. Routine implementation details stay in specs. Recommend scoped small-model research/review, e.g. Luna or Haiku where available. Delegate only when authorised.

Copy [.galicia/templates/adr.md](../../.galicia/templates/adr.md). Replace every placeholder before review.

Use NNNN-short-title.md. Status is proposed, accepted, rejected or superseded. Include context, decision, alternatives, consequences, evidence and linked specs. Accepted ADR remains historical evidence; supersede through new ADR, link both directions. Never silently rewrite old rationale.
