# Termi

Termi's file editor supports reading Markdown and editing its source.

## Language

**Preview**:
The rendered view of the current Markdown document, including unsaved edits.
_Avoid_: Render mode, formatted editor

**Source**:
The editable raw Markdown document from which the preview is rendered.
_Avoid_: Raw mode, Markdown code

**Placeholder**:
A text marker representing an image or HTML that the preview does not render.
